## 为 dm_hook.dll 添加 COM 支持 — 实施计划

### 目标
使 `import win32com.client; dm = win32com.client.Dispatch('dm.dmsoft')` 能够工作。

### 架构设计

```
win32com.client.Dispatch('dm.dmsoft')
    ↓ 注册表查找 ProgID → CLSID
    ↓ LoadLibrary("dm_hook.dll")
    ↓ DllGetClassObject(CLSID, IID_IClassFactory)
    ↓ ClassFactory.CreateInstance() → CDmObject (IDispatch)
    ↓ IDispatch::GetIDsOfNames("ver") → DISPID
    ↓ IDispatch::Invoke(DISPID) → 调用 dm_ver()
```

### 新增文件

**1. `dm_com.h`** — COM 接口声明
- CLSID 和 ProgID 定义
- `CDmObject` 类：实现 `IDispatch`
- `CDmClassFactory` 类：实现 `IClassFactory`
- DLL 导出函数声明

**2. `dm_com.cpp`** — COM 实现
- 全局引用计数、锁
- `CDmObject` 实现（IUnknown + IDispatch）
- `CDmClassFactory` 实现
- 4 个标准 DLL 导出函数

### 修改文件

**1. `dm.cpp`** — 添加 COM 状态切换支持
- 添加 `thread_local DmState* g_comOverrideState = nullptr;`
- 添加 `void dm_setComState(DmState* s)` 函数
- 修改 `GetDmState()`：
  ```cpp
  DmState* GetDmState() {
      if (g_comOverrideState) return g_comOverrideState;  // COM 优先
      // ... 原有 TLS 逻辑 ...
  }
  ```

**2. `CMakeLists.txt`** — 添加 `dm_com.cpp` 到构建

### 关键实现细节

#### CDmObject 状态管理
- 每个 COM 对象拥有自己的 `DmState state` 成员（非 TLS）
- 在每个方法调用前通过 `dm_setComState(&state)` 切换到 COM 对象状态
- 调用完成后恢复为 `nullptr`
- 使用 `InterlockedIncrement/Decrement` 管理引用计数

#### IDispatch 实现
- `GetTypeInfoCount` → 返回 0（无类型库，纯晚绑定）
- `GetTypeInfo` → 返回 `E_NOTIMPL`
- `GetIDsOfNames` → 在排序后的函数名数组中二分查找
- `Invoke` → 通过函数分发表调用

#### 函数分发表
定义一个结构体数组：
```cpp
struct DispFunc {
    const char* name;           // 函数名，如 "ver"
    DISPID id;                  // 分发 ID
    uint8_t paramCount;         // 参数个数
    uint8_t hasOutParams;       // 是否有输出参数
    HRESULT (*handler)(DmState*, VARIANT* ret, const VARIANT* args, uint32_t argCount);
};
```

每个函数通过宏或 lambda 注册 handler。handler 负责：
1. 从 VARIANT 数组提取参数
2. 调用对应的 `dm_xxx` C 函数
3. 将返回值写入 `ret` VARIANT
4. 处理输出参数（`long*`, `float*`, `double*`）

#### 函数签名分组
根据参数模式，约需要 30 种 handler 模板：
- 无参：`long func()`, `const char* func()`
- 单参：`long func(long)`, `long func(const char*)`
- 多参：`long func(long, long)`, `long func(long, long, const char*)`, 等
- 输出参数：`long func(long, long, long*)` — 需要包装为返回值或 SAFEARRAY

#### DLL 导出函数
```cpp
STDAPI DllGetClassObject(REFCLSID rclsid, REFIID riid, LPVOID* ppv);
STDAPI DllCanUnloadNow();
STDAPI DllRegisterServer();    // 注册 CLSID + ProgID 到注册表
STDAPI DllUnregisterServer();  // 从注册表清除
```

#### 注册表注册内容
DllRegisterServer 写入：
```
HKCR\CLSID\{GUID} → "dm.dmsoft"
HKCR\CLSID\{GUID}\InprocServer32 → "C:\path\to\dm_hook.dll"
HKCR\CLSID\{GUID}\InprocServer32\ThreadingModel → "Both"
HKCR\dm.dmsoft → "dm.dmsoft"
HKCR\dm.dmsoft\CLSID → {GUID}
```

### 实施步骤

1. 在 `dm.cpp` 中添加 `g_comOverrideState` 和 `dm_setComState()`
2. 创建 `dm_com.h` — CLSID、类声明
3. 创建 `dm_com.cpp` — 完整的 COM 实现
4. 修改 `CMakeLists.txt` 添加 `dm_com.cpp`
5. 构建 DLL、注册、测试

### 注意事项
- `ole32` 和 `oleaut32` 已在链接列表中，无需修改 CMake 链接库
- `CMAKE_WINDOWS_EXPORT_ALL_SYMBOLS` 会自动导出 4 个 COM 函数
- 使用 `regsvr32 dm_hook.dll` 注册，`regsvr32 /u dm_hook.dll` 注销
- 测试脚本：`python -c "import win32com.client; dm = win32com.client.Dispatch('dm.dmsoft'); print(dm.Ver())"`
